## 📖 思想宣言 (Manifesto)

**TheDAO** 不是现有公链（如比特币、以太坊）的简单分支或渐进式修补，而是一场**回归第一性原理、从零设计的区块链底层范式革命**。

现代区块链技术虽然消解了中心化中介，却在底层全盘继承了工业时代的**私有产权与资本积累逻辑**：
- **UTXO 与账户余额机制**：在状态层将“排他性私有占有”铸造为唯一的数学公理；
- **PoS 与治理代币**：使“谁出资多谁拥有话语权”（富豪政治 Plutocracy）合法化；
- **金融化与投机寻租**：公链沦为流动性收割与资本屯居的博弈场，背离了公共协作的初衷。

> **TheDAO 提出根本性追问**：  
> *如果区块链的状态机不再记录“谁拥有什么”，而是流转“谁创造了什么、系统如何协同”，世界会怎样？*

TheDAO 确立了**“去中心化”与“去所有制（Post-Ownership / Disownership）”**的双轮驱动，旨在构建一个**无私有产权壁垒、无资本寡头垄断、完全由算法与协同网络自主演化的去中心化公共世界**。

## 🏛️ 核心公理与世界观 (Core Axioms)

```
传统区块链范式 (The Proprietary Paradigm)
  [私有产权] ──> [横向甲乙契约 (人雇佣人/买卖)] ──> [资本积累与质押垄断] ──> [金融寻租与阶级分化]

TheDAO 拓扑范式 (The Single-Party A Commons)
  [去所有制] ──> [纵向单一甲方 (系统为甲/全员为乙)] ──> [不可累积积分与经验衰减] ──> [自组织繁荣与生态涌现]
```

### 1. 单一甲方模型 (The Single-Party A Model)
- **系统是唯一的抽象甲方，所有用户均为独立的乙方**；
- 用户与用户之间是独立的，**不存在横向的甲乙从属、雇佣或买卖关系**。
- 人不能“买断”另一个人，也不能占有生产资料向他人收租。从拓扑结构上根除人剥削人与资本奴役的可能。

### 2. 消解权力与权利：只有“权限与权益”
- **无“权力（Power）”**：没有任何人或特权阶层能够对其他成员行使政治支配或强制意志；
- **无“权利（Rights）”**：不设立排他性的私有特权；
- **唯有“权限（Permission）”与“权益（Benefit）”**：信任层级决定功能性的处理权限，公地贡献赋予当期资源的调用权益。

## ⚙️ 任务与创造引擎 (The Task & Creation Engine)

### 1. 人即系统，诉求即任务
系统虽然是一个抽象概念，但系统由活生生且具体的人构成。人需要什么，系统就需要什么：
- **诉求显化**：用户发布任务，可以是需求、求助、协作愿景；
- **自由创造**：用户若想创造新事物，只需自己发布一个任务，内容即为该创造构想，随后**自领并交付成果**，彻底消灭被资方雇佣的异化劳动。

### 2. 自然增值法 (Natural Appreciation Method)
系统本身不具备主观定价能力，定价权归属于全体乙方构成的网络：
- **时间与共鸣决定价值**：任务随时间流逝自然增长；
- **动态增量算法**：在单位时间内，任务价值的增长速率由支持与反对者决定：
  $$\Delta V / \Delta t \propto n \quad (n = 支持人数 - 反对人数)$$
- 真正符合群体福祉与迫切需求的任务自发加速升值；无人问津或恶意的任务增长停滞甚至萎缩。

### 3. 申报与多维加权认领 (Multi-parameter Claiming)
当任务价值因增值吸引多人竞争认领时，系统绝不采用简单的“先到先得”或“唯高分论”：
- **双参数自主申报**：认领者自主申报 **承诺完成时间** 与 **所需系统资源（可选）**；
- **多维综合筛选**：系统结合申报参数的合理性、用户的信誉分与经验覆盖度（若经验不足以覆盖所申请的系统资源，系统将审慎评估以防跑路）；
- **引入随机权重 (Random Weight)**：在合格候选人中加入随机概率，打破顶级用户的垄断闭环，保障新人的发展机会与生态流动性。

## 💎 价值与去资本经济模型 (The Post-Capital Economy)

### 1. 资产全量归入公地
任务交付并验收合格后，产出的全部资产（代码、知识、工具、实体物）**归系统所有、归系统支配**，永久不可被任何个体私有化或建立收费壁垒。

### 2. 双轨价值分配体系
用户通过交付任务，从系统（甲方）获得劳动价值确认，体现为**双轨制**：
- **经验 (Experience)**：记录个体的历史有效贡献；
  - **时间自然衰减**：经验随时间平滑衰减，新人只要持续贡献即可追赶，彻底杜绝早期“元老贵族”靠远古工分永久食利；
  - **跨级衰减**：用户经验与所接任务价值差距过大时，获得的经验收益自动衰减，防止高阶刷低级任务投机与降维内卷，防劣币逐良币，保护新人生态位并倒逼高阶攻坚。
- **积分 (Points)**：系统以周期（约 720 小时）为单位进行清算，依个人有效经验在全网占比进行分发。

### 3. 积分的数学铸造、动态折旧与反资本法则
每一个结算周期 $T_{cycle}$，系统总积分按严密的状态方程发行：$P_{total} = (V_{residual} + V_{current}) \times k_{zombie}$（参数 $k_{zombie}$ 源自《道德经》“生之徒十有三”，补偿非活跃用户，确保活跃积分充沛覆盖公地资产）。未兑换的剩余资产执行**强制动态折旧**，消除僵尸资产与虚假通胀；积分按贡献权重 $\alpha$ 与普惠福利权重 $\beta$ 双轨发放。

积分是公地资源调用的物理凭证，受严格协议约束：
- **不可累加 (Non-accumulative)** 与 **不可结余 (Non-carryover)**：周期清零，杜绝资本积累；
- **不可转让 (Non-transferable)** 与 **不可赠送 (Non-giftable)**：杜绝黑市套利与阶级代际继承；
- **1:1 绝对刚性定价**：资产积分标价严格等同于账面内在价值，兑换即彻底销毁（Burn into Void）。

### 4. 基础福利底线 (Basic Welfare)
- 每一结算周期中，系统从积分总池中抽取固定比例 $\beta$ 作为基础福利；
- **设有准入门槛**：仅面向通过基本认证、具有真实参与资格的正式成员发放（明确排除临时游客与未达门槛的空账号），构筑抵御剥削与保障尊严的坚固兜底。

## 📦 资产管理与虚实公地 (Assets & Physical Commons)

### 1. 虚实统一与“使用时间物理学”
- **全量归公**：一切可交付的成果（代码、硬件、空间、生产资料）全属系统公地；
- **非排他型资产**（数字开源）：链上公开地址，向全人类免费开放调用，零积分门槛；
- **排他型资产**：兑换本质为**购买使用时间**（消耗品为终身使用时间，耐用品/空间为有限使用时间）。

### 2. 去稀缺性：只有缺货，没有稀缺
- **无序等待队列**：库存不足时不涨价、不拍卖，申请者进入无 VIP 特权的等待队列；
- **随机平权补货**：新成果交付时在等待队列中随机兑换；
- **生产力召集令**：缺货队列直接转化为透明的社会需求信号，倒逼并激励新生产力涌现。

### 3. 三阶段质押接力与自组织看护
- **产物免预填**：发布者无需预先填报产物清单，不强求预知未发生之事；成果交付后暂存创作者手中（冻结状态），系统自动派生【产物管理任务】，由独立管理员进行现场清点、核实验伪与正式入库；
- 管理员认领需刚性质押 **80% 资产价值经验 + 30% 本人信誉分**（数学限制单人至多并发 3 个任务）；
- 管理员切身利益驱动成为第一质检员，无误交接后资产正式入库开放兑换，全程接受全网监督。

## 🌐 外部世界交互与跨界贸易 (External World Trade)

- **三权分立采购（买）**：采购者认领任务寻源锁定订单（不碰钱） $\rightarrow$ 系统调用外汇管理员对公直付（见不到货） $\rightarrow$ 独立资产管理员现场清点质押入库。
- **内部优先与双轨出海（卖）**：过剩资产优先以排他类资产使用配额下发内部基础福利；富余资产通过【系统级外汇任务】（外部自愿注资）与【代理人机制】（出海面向外部市场销售）换回外汇与战略原材料。
- **宪制级绝对防火墙**：**严禁内部用户兑现法币**，系统作为外部法币的单向能量汇，彻底阻隔外部金融资本投机与洗钱渗透。

## 🛡️ 信任与安全免疫系统 (Trust & Immune System)

### 1. 系统的第二命脉：信誉分与信任层级
- **信誉分 (Reputation)**：完全由守约交付任务沉淀而来，直接映射为**信任层级 (Trust Tiers)**；
- **权限权益申请权**：不同信任层级开放不同专业领域的“权限与权益申请权”，严密阻隔小号女巫攻击。

### 2. 乐观验证与追溯期 (Optimistic Verification)
- **乐观验证**：系统对任务交付成果默认假定为合格，保障协作的高流转效率；
- **追溯窗口**：设置相当于任务“发布至完成时间三分之一”的追溯期。追溯期内成果接受全网审视。

### 3. 同构递归验收与终止收敛机制 (Dispute Convergence)
- **质疑即任务**：任何对成果存疑的用户均可在满足质押门槛后发起“验收任务”；
- **递归收敛与终止判定**：依据所涉资产与任务价值设有明确的系统终止判定条件，杜绝无限套娃与政治死循环，强制执行终局清算（具体终止算法后续详谈）。

### 4. 有限责任上限与正义激励
- **有限责任上限原则 (Bounded Liability)**：任务失败或违约的最大惩罚上限，严格等同于“该任务发布时所关联系统资产的最高价值”，消除劳动者的无限恐惧；
- **挽回损失百分比提成**：质疑胜利者按“为系统实际挽回损失”的一定比例获得直接价值奖励与信誉跃迁，驱动社区自发免疫。
