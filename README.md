## 📖 概述 (Manifesto)

**TheDAO** 不是现有公链（如比特币、以太坊）的简单分支或渐进式修补，而是一场**回归第一性原理、从零设计的区块链底层范式革命**。

现代区块链技术虽然消解了中心化中介（银行、云巨头），却在底层全盘继承了工业时代的**私有产权与资本积累逻辑**：
- **UTXO / 账户余额机制**：在状态层将“排他性私有占有”铸造为唯一的数学公理；
- **PoS 与治理代币**：使“谁出资多谁拥有话语权”（富豪政治 Plutocracy）合法化；
- **金融化与投机寻租**：公链沦为流动性收割与资本屯居的博弈场，背离了公共协作的初衷。

> **TheDAO 提出根本性追问**：  
> *如果区块链的状态机不再记录“谁拥有什么”，而是流转“谁创造了什么、系统如何协同”，世界会怎样？*

TheDAO 确立了**“去中心化”与“去所有制（Post-Ownership / Disownership）”**的双轮驱动，旨在构建一个**无私有产权壁垒、无资本寡头垄断、完全由算法与协同网络自主演化的去中心化公共世界**。

## 🌌 思想渊源：从私有产权到数字公地

```
传统区块链范式 (The Proprietary Paradigm)
  [私有产权] ──> [资本加权 (PoW/PoS)] ──> [财富聚集与质押垄断] ──> [公地私有化/金融寻租]

TheDAO 新范式 (The Post-Ownership Commons)
  [动态流转] ──> [协同共识网络] ──> [去所有权/无主形态] ──> [自组织繁荣与生态涌现]
```

### 1. 传统公链的“所有制困境”
比特币确立了去中心化账本，但它将“价值”等同于“稀缺所有权的排他性控制”；以太坊带来了图灵完备，但智能合约中无处不在的 `Ownable`、ERC-20 余额及代币加权治理，导致权力再度集中于巨鲸与早期资本手中。**去中心化的技术外壳下，包裹着愈发中心化的资本权力。**

### 2. “生而不有”：去所有制的哲学内核
老子云：“万物作而弗始，生而不有，为而不恃，长而不宰”。  
在 TheDAO 的图景中：
- **协议不赋予任何实体对状态、协议或资源的终极排他所有权**；
- 资源与流动性属于**不可被私有化的公共池（Common Pool）**；
- 个体享有的是**使用权（Access）、协同权（Co-action）与动态收益归属（Dynamic Attribution）**，而非永久占有与食利特权。

## 🛠️ 本地浏览与工程规范

本项目采用 Markdown 结构化编写，并通过 GitHub Actions 与 Quartz 引擎全自动构建发布至数字花园。

### 1. 本地阅读
直接使用支持 Wikilink 的 Markdown 编辑器（如 [Obsidian](https://obsidian.md/)）打开当前工作区，即可享受网状知识图谱与双向链接体验。

### 2. 站点构建配置
- [`quartz.config.yaml`](./quartz.config.yaml)：站点属性、主题调色盘与插件系统配置。
- [`custom.scss`](./custom.scss)：数字花园自定义视觉样式。
- [`logo.svg`](./logo.svg) / [`logo.png`](./logo.png)：TheDAO 视觉符号（莫比乌斯环与分布式协同节点）。
- [`.github/workflows/deploy.yml`](./.github/workflows/deploy.yml)：GitHub Actions 全自动构建并发布至 GitHub Pages。
